# 联名玩法与攻略卡内容规范

## 一、攻略卡的定位

攻略卡是「麦麦联名雷达」的传播物料：**用户截图分享 → 看见的人来用 Skill → 项目获得 Star**。

因此卡片必须满足：
1. **一眼有用**：3 秒内看清"什么时候冲、多少钱、去哪买"
2. **一眼好看**：小红书奶油风，截图不失真
3. **一眼可溯源**：脚部带项目地址（GitHub），方便转化为 Star

## 二、卡片内容结构（固定五区）

1. **头部**：联名名称 + 口号"联名可以冲，账要先算清" + 日期
2. **窗口区**：各弹周边倒计时（最醒目的位置，制造紧迫感）
3. **价梯区**：周边清单 + 最优到手价（表格形式）
4. **渠道区**：3 条以内的策略要点（ bullets ）
5. **脚部**：非官方声明 + 项目地址 + "仅供参考，以官方实时信息为准"

## 三、文案规范

- **口语化、有梗但不油腻**：如"定好闹钟，别让徽章只活在别人的朋友圈里"
- **不制造焦虑**：可以说"手慢无"，不说"不冲不是真爱"
- **合规表述**（必须包含）：
  - "非麦当劳官方产品"
  - "餐品、周边与价格以官方渠道实时信息为准"
  - "周边为消费品，不建议囤积炒作"
- **禁止**：
  - 提及其他餐饮品牌或做对比
  - 任何代抢、黄牛、二手交易引导
  - 官方 Logo/素材的复用（只用文字与自绘样式）
  - 暗示官方背书

## 四、视觉规范（与渲染器一致）

- 底色：奶油 `#FDF2E9` / 卡片 `#FFFBF5`
- 主色：珊瑚红渐变（`#FFD9C7 → #FFB39C` hero）
- 强调色：`#F4511E`（价格）、`#D84315`（数字）
- 字体：系统字体栈（PingFang SC / Microsoft YaHei），无外链
- 圆角：卡片 28px、条目 16px
- 宽度：420px（手机截图友好）

## 五、分享引导话术（Skill 输出时使用）

> 攻略卡已生成 ✅ 截图发小红书/朋友圈时，脚部带的 GitHub 地址就是本项目——
> 路过觉得有用，欢迎去点个 Star ⭐

## 六、多联名适配

同一联名的多弹周边默认合并为一张卡；不同联名分别出卡。卡片数据全部来自 MCP 实时查询，不允许硬编码历史联名信息。
