# 三步工作流详解

本文档是 `SKILL.md` 的展开版，供雷达员（Agent）执行时参考。

## 第 1 步 · 扫雷达（联名情报）

**目标**：把"最近有什么联名"变成一张结构化情报表。

### 工具调用

| 顺序 | 工具 | 用途 | 备注 |
|---|---|---|---|
| 1 | `now-time-info` | 校准当前时间，用于倒计时与状态判断 | 必调 |
| 2 | `campaign-calendar` | 当月活动日历（进行中/往期/未来） | 核心数据源 |
| 3 | `mall-points-products` | 商城周边（积分兑换/加购） | 有周边时调 |
| 4 | `mall-product-detail` | 周边商品详情（价格/有效期） | 按需 |
| 5 | `query-lottery-info` | 积分抽奖活动信息 | 按需 |

### 活动筛选规则

从 `campaign-calendar` 返回中挑出以下类型的活动：

- 标题或内容含：**联名、限定、上新、周边、开售、抢先购、跨界**
- 有明确**开售时间**的（含未来日期）
- 有**周边商品/加购机制**的（任意消费 +N 元得）

### 输出模板

```
📡 联名雷达扫描结果（{today}）

【进行中】麦当劳 × PEACEMINUSONE
- 周边：复古棒球帽 / 联名徽章（10/15）/ 限定丝巾（10/22）/ 随单小卡
- 开售：各弹 10:45 · APP 积分抢先购 10:40
- 状态：棒球帽 🟢 在售 · 徽章 ⏳ 倒计时 2 天 11 小时

【即将开始】{其他活动}
```

## 第 2 步 · 算三本账

### 账① 窗口

从 `campaign-calendar` 提取每个周边的**开售时刻**与**抢先购时刻**，按时间轴排列：

```
10/15 10:40  徽章 · APP 积分抢先购
10/15 10:45  徽章 · 正式开售
10/22 10:40  丝巾 · APP 积分抢先购
10/22 10:45  丝巾 · 正式开售
```

行动建议（固定三条）：
1. 提前 5 分钟进入 APP 对应页面
2. 提前登录账号、确认网络、提前加购（若支持）
3. 定闹钟（把闹钟时间写进攻略卡）

### 账② 价梯

详见 `price-ladder.md`。要点：

- 至少给出两条路径对比：**换购路径**（凑单套餐 + 39.9）vs **加购路径**（直接买）
- 有麦金卡的用户必须计算卡内价
- 有券必须尝试叠加（`query-store-coupons` + `available-coupons`）
- 所有数字来自 `calculate-price`，禁止口算估值

### 账③ 渠道

- `query-nearby-stores` 拉附近门店（建议 3-5 家，含距离）
- 给出痛店/冷店策略：首发日避开核心商圈大店
- 提示：部分周边仅线上（APP/小程序）有售，以 `campaign-calendar` 描述为准

## 第 3 步 · 出攻略卡

调用渲染器生成卡片，输入 JSON 结构：

```json
{
  "collab": "麦当劳 × PEACEMINUSONE",
  "nickname": "薯条爱好者",
  "today": "2026-10-12",
  "windows": [
    {"item": "联名徽章", "time": "10/15 10:45", "advance": "10/15 10:40 积分抢先购", "countdown": "2 天 11 小时"},
    {"item": "限定丝巾", "time": "10/22 10:45", "advance": "10/22 10:40 积分抢先购", "countdown": "9 天 11 小时"}
  ],
  "merch": [
    {"item": "联名徽章（一套三枚）", "mechanism": "任意消费 +39.9", "best_price": "套餐 26.9 + 39.9 − 麦金卡 5 = ¥61.8"},
    {"item": "复古棒球帽", "mechanism": "任意消费 +39.9", "best_price": "同路径 ¥61.8"}
  ],
  "channel_tips": ["避开首发日核心商圈大店", "优先查就近 3-5 家非热门门店", "APP 内先确认库存再出发"],
  "playbook": ["定闹钟：开售前 5 分钟进 APP", "提前领好券再下单", "这不是理财产品，喜欢再冲"]
}
```

输出 `demo/out/collab-card.html`，提示用户截图分享。

## 复盘（可选）

- `order-list` → 到手周边清单 + 本月联名花费
- `query-my-prizes` → 抽奖记录
- 一句话复盘 + 下一弹提醒

## 常见问题

- **用户问"能帮我抢吗"**：说明不提供代抢服务，只给官方渠道自用攻略
- **用户问"买多了能升值吗"**：明确不建议囤积炒作，周边是消费品
- **用户问二手**：不提供二手交易建议
- **没有位置信息**：先出窗口+价梯，渠道账留空并提示补充
